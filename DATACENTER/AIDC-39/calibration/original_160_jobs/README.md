# 训练作业与机组组合联合调度

在 16 号母线设置一个 300 MW AIDC，包含 64 个等效算力块。背景负荷峰值为公开网架原始负荷的 85%。公共电网和 UC 方程见 [GRID_MODEL.md](../GRID_MODEL.md)。

## 参数与决策

160 个作业 \(j\) 分别具有到达时段 \(r_j\)、完成截止边界 \(d_j\)、并行块数 \(k_j\)、工作量 \(W_j\) 和流转时间成本 \(h_j\)。输入中的截止边界允许等于 96；运行区间左闭右开。每个作业占用固定数量算力块，启动后不能暂停或换档。

| 运行档位 | 吞吐率，相对标准档 | 单个运行块功率 MW |
|---|---:|---:|
| eco | 0.70 | 2.0 |
| balanced | 0.85 | 2.7 |
| fast | 1.00 | 3.5 |

站点固定 IT 功率为 16 MW，PUE=1.25，含冷却及辅助系统后的最大设施功率恰为 \(1.25(16+64\times3.5)=300\) MW。

二元变量 \(x_{jks}\) 选择作业 \(j\) 在档位 \(k\) 下于时段 \(s\) 开始。运行长度
\[
 L_{jk}=\left\lceil\frac{W_j}{k_j q_k\Delta t}\right\rceil.
\]
只创建满足 \(r_j\le s\) 且 \(s+L_{jk}\le d_j\) 的候选。整数时段取整产生的末时段余量仍按完整时段计功率，是本模型的保守能耗约定。

## 优化问题

\[
 \min\; C^{UC}+C^E+\sum_{j,k,s}h_j(s+L_{jk}-r_j)\Delta t\,x_{jks}
\]

\[
 \sum_{k,s}x_{jks}=1,\qquad
 \sum_{j,k,s:\,s\le t<s+L_{jk}}k_jx_{jks}\le64,
\]

\[
 P^{grid}_{16,t}=1.25\left[16+\sum_{j,k,s:\,s\le t<s+L_{jk}}k_jp_kx_{jks}\right]\le300.
\]

加上完整的网络潮流、支路、UC 与爬坡约束。最后一个成本分项是“到达到完成”的流转时间，包含等待和执行，不只是排队时间。

## 数据和对照

种子 101 先在最快档位下随机放置 160 个作业，聚合容量不超过 60 块，再扩展每个作业允许的开始窗口。作业块数从 2、4、8 中抽取，最快执行长度为 2～12 时段，流转成本为 3～12 基准美元/小时。`witness_*` 仅记录生成时的算力可行排程，正式模型把它作为 MIP start，不把它当最优解。

对照按截止时间、到达时间和作业编号排序，使用最快档位，在算力容量允许的最早连续区间执行；固定该排程后优化同一电网。若排不下或电网不可行，保留失败状态。主问题和对照均必须逐个完成相同的 160 个作业。

详细数组及单位见 `data/aidc.json` 和 [DATA_SCHEMA.md](../DATA_SCHEMA.md)。完整结果保存各作业的开始时段、档位和长度，以及 96 时段的机组、潮流与 AIDC 负荷。
