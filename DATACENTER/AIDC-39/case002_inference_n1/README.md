# 线路 N-1 安全约束下的多站点推理服务调度

在母线 4、16、27 各接入最大取电 200 MW 的 AIDC。每站 48 个算力块、3200 GB 模型内存；PUE 分别为 1.20、1.25、1.30。六个请求区域、六类模型的请求量在 96 个时段给定。基础负荷峰值为原始值的 68%。

## 模型副本、算力与业务

整数变量 \(n_{dmt}\)、\(b_{dmt}\)、\(q_{dmt}\) 分别为可服务副本、正在启动的副本和停用数；每个副本占一个聚合算力块。连续变量 \(y_{rmdt}\) 是路由到站点 \(d\) 的请求速率，单位 requests/s。

\[
 n_{dmt}=n_{dm,t-1}+b_{dm,t-1}-q_{dmt},\quad
 n_{dmt}\ge\sum_{\tau=\max(0,t-4)}^{t-1}b_{dm\tau}.
\]

启动耗时一个时段，完成启动后至少在线四个时段。初始副本已就绪且已满足最短在线时长。时域末尾不允许无法履行最短在线期的新启动。启动期占算力、内存并消耗功率，但不处理请求。

\[
 \sum_m(n_{dmt}+b_{dmt})\le48,\qquad
 \sum_m M_m(n_{dmt}+b_{dmt})\le3200,
\]
\[
 \sum_d y_{rmdt}=\lambda_{rmt},\quad
 \sum_r y_{rmdt}\le\mu_m n_{dmt},\quad y_{rmdt}\ge0.
\]

若通信时延 \(\ell_{rd}\) 加处理时延 \(\ell_m\) 超过服务上限 \(L_m\)，对应路由固定为零。每个区域—站点链路上限 50 Gbps，站点总带宽上限 150 Gbps；流量按请求速率乘每请求 Mbit 后除以 1000 换算。这里的时延与吞吐量是合成的固定服务档位，并非真实排队系统的尾延迟认证。

## 用电与目标

\[
 P^{grid}_{dt}=\mathrm{PUE}_d\left[8+\sum_m\left(p_m^{idle}n_{dmt}+2b_{dmt}
 +\frac{p_m^{busy}}{\mu_m}\sum_r y_{rmdt}\right)\right]\le200.
\]

各模型 \(p_m^{idle}=1.1+0.08m\) MW，\(p_m^{busy}=1.75\) MW。目标为 UC 与发电成本，加副本启动及部署成本（每次 18+12 美元），以及按百万请求计的通信成本。关闭副本即时释放资源；请求不得跨时段积压。

## 安全约束

对 46 条支路逐一删除并检查图连通性，得到完整的 35 个非孤岛事故。其余 11 条会造成孤岛的退出未包含在本模型中，也未包含发电机事故。

各事故与基态共享发电出力和 AIDC 用电，采用预防性调度，不设置事故后重新路由或再调度。优化中使用
\[
 f^{(c)}_{lt}=f_{lt}+\mathrm{LODF}_{lc}f_{ct},\qquad l\ne c,
\]
同时满足事故后正常热限值 `rateA` 与支路相角差限制。独立校验不使用这些 LODF，而是在每个退出拓扑上重建节点导纳矩阵、求解相角并复核全部线路。

## 数据与对照

请求使用种子 202 的平滑日变化与小扰动；所有参数在 `data/aidc.json` 中公开。区域 0/1、2/3、4/5 分别以三个站点为就近站点。初始每类副本数等于覆盖本地全日峰值所需的整数数量。

对照固定上述副本配置和就近路由，优化同样的 UC 与全部 35 个事故约束。正式解与对照服务完全相同的请求；若对照不可行，不计算成本改善率。
